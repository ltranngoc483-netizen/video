## Editing

On a fresh system install dependencies with `npm install`, then `npm run dev` (Studio port3018). `BellWitch` is the full composition; `MissingVerdict`, `InvisibleSiege`, `FatalVial`, `JacksonFunnel` are individually registered scenes. Root metadata and each timeline scene are explicit JSX nodes.

`node scripts/render.cjs --review-only` exports fourteen review frames and four still assets. `--render-only` skips those exports and renders picture. Substitute your own Chrome executable for the workspace-specific wrapper path in that script. `python scripts/audio.py` prepares the existing narration clips, sound design, final audio and SRT (numpy/soundfile needed). `python scripts/finalize.py` muxes picture and audio; `python scripts/validate.py` checks the completed movie. The WAVs are supplied so regenerating TTS is unnecessary. Regenerating voice needs Kokoro ONNX and voice files at the external local paths documented in scripts/voice.py.
