# The Invisible World — QR Short

30 seconds, 1080×1920, 30 fps. Four independently editable Remotion scenes, photographic papercraft assets, macro shot changes, finder locks, independently moving grid cutouts, data pulses, vault mechanisms and a five-second CTA. Motion transforms use a 15-step-per-second stop-motion cadence inside the 30 fps video.

Narrator: local Kokoro `am_michael`, US male draft. This is NOT ElevenLabs Marcus; no ElevenLabs tool was available. Narration retains the supplied English script. Phrase durations were measured from generated audio and fitted by small pitch-preserving tempo changes. English SRT has 16 cues.

Preview: `npm run dev` on port 3011. Install dependencies with `npm ci` if using a fresh checkout. Render `QRShort` muted with Remotion to `out/qr-short-native.mp4`, then run `python scripts/finalize.py`. `scripts/validate.py` requires numpy and soundfile. The local renderer uses a system-specific Chromium wrapper; substitute your available Chrome executable when rendering elsewhere.

`scripts/inspect.cjs` exports review frames and four 1080×1920 PNG assets. The first three PNGs contain artwork only; Scene04Asset is the complete branded CTA. `Thumbnail` exports the cover with MORE THAN A SCAN.

The QR pattern is an illustration, not a production QR code. Finder patterns locate a code; its modules represent data, not necessarily encrypted data. A payment app and financial systems handle authorization after decoding. Scanning is not confirmation that money moved. No universal 300ms completion claim is made. Vaults and conduits are explanatory visual metaphors, not a literal financial network diagram.
